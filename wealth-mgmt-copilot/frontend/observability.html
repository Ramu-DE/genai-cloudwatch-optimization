📋 Useful CloudWatch Insights Queries

Bedrock Invocation Summary

SOURCE '/aws/bedrock/modelinvocations' | stats count() as invocations, avg(inputTokenCount) as avg_input, avg(outputTokenCount) as avg_output, avg(invocationLatency) as avg_latency by modelId | sort invocations desc

Agent Performance by Type

SOURCE '/aws/lambda/wealth_mgmt_agent_router_lambda' | filter @message like /AgentCore invocation/ | parse @message "Agent: * | Client: *" as agent, client | stats count() as requests, avg(@duration) as avg_duration by agent

Error Analysis

SOURCE '/aws/lambda/wealth_mgmt_agent_router_lambda' | filter @message like /Error|Exception|FAIL/ | fields @timestamp, @message | sort @timestamp desc | limit 50

Compliance Audit Trail

SOURCE '/ecs/compliance-checker' | filter @message like /FLAGGED|KYC|AML|compliance/ | fields @timestamp, @message | sort @timestamp desc | limit 100
